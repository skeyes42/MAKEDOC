# Customer Site Analysis

This site analysis is performed before MAKEDOC is implemented at an installation. I followed this process when developing the MAKEDOC.db database. This process looks at a customer's procurement artifacts include:

- Actual assembled requisition, solicitation and award documents from each of the main dollar-amount categories, e.g. micro, standard and complex for small, medium and large dollar procurements.
- Customer documentation on procedures for doing procurement in the main dollar-amount categories.
- Any forms used in the procurement process.
- Any lists of data collected from the user during the procurement process.
- Any special clauses (e.g. DEI, HAZMAT) that may be included in the procurement process.
