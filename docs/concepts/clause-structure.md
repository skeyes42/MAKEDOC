# Clause Structure for MAKEDOC System
## Overall Structure
A **clause** is made up of two parts:
- Section header 
- Clause content
## Section Header
This part of the clause specifies the section number and the title of the clause. The section number is specified as follows

**SECTION {SecNo} &mdash; \<title\>** where {SecNo} is a plain text fill-in used by the system to consequtively number all of the sections of a document. It is supplied by the system when
the document is assembled.

## Clause Content 
This is the actual content of the clause. It can contain any valid Word DOCX text.
