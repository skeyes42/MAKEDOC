# Line Items in MAKEDOC

## Explaining line items
Line items are an important part of any procurement. MAKEDOC is designed to collect line item information from the user -- as a prerequisite for generating the document. Once the line item information is collected, the user can choose the **phase** of the requisition for the new document: requisition, solicitation or award. Since the line item information contains the total amount of the procurement, the **tier** (dollar amount) can be determined. The combination of the phase and the tier determines the **doctype** which is used to select the appropriate clause library for generating the document. The clause libraries separate the clause into bins based on the phase/tier combination. 

The phases are **req** for requisition, **sol** for solicitation, and **awd** for award.
The tier are **micro** for low-dollar, **std** for medium dollar, and **cmplx** for high dollar.

Here are the different bins:

|    Phase     |   Low dollar  | medium dollar |  high dollar  |
|--------------|---------------|---------------|---------------|
| Requisition  | req-micro     |  req-std      |  req-cmplx    |
| Solicitation | sol-micro     |  sol-std      |  sol-cmplx    |
|   Award      | awd-micro     |  awd-std      |  awd-cmplx    |

Line item information includes the following fields:

- **Line number** the order of the particular row in the line item table
- **Description** a short description of the line item
- **NAICS** a code indicating the type of good or service
- **Quantity** the quantity of the line item (in units)
- **Unit** the unit of measure of the line item
- **Price** the price of each unit of the line item good or service
- **Extended Price** is equal to the price times the quantity

**Total Price** is the sum of the extended prices.

## Implementing line items
On the backend, line items are implemented with the **Lineitem table**. Here's the schema for this table:

CREATE TABLE LineItem (
    LineItemID   TEXT PRIMARY KEY,
    InstanceID   TEXT NOT NULL,
    LineNum      INTEGER NOT NULL,
    Description  TEXT NOT NULL,
    NAICS        INTEGER DEFAULT 0,
    Unit         TEXT NOT NULL,
    Quantity     REAL NOT NULL,
    UnitPrice    REAL NOT NULL,
    FOREIGN KEY (InstanceID) REFERENCES Instance(InstanceID)
);

On the frontend, a line item table is generated by the system by specifying a line item plain text fill-in: **{lineitem}**. During assembly (after the user click on the generate button in the Assembly form), when the system encounter this plain text fill=in tag, the system generates the DOCX text from the line item table. This DOCX is inserted into the document under assembly.

A typical line item table looks like:

| Item No. |      Description    | NAICS  | Quantity | Unit | Price     | Extended Price |
|----------|---------------------|--------|----------|------|-----------|----------------|
|   1      | Car batteries       | 34254  |   20     | EA   | $150.00   |  $3,000        |
|   2      | Pencils             | 12455  |  100     | BOX  |  $20.00   |  $2,000        |

Total price: $5,000.
