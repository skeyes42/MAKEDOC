Methodology

This report was produced by fillin_audit.R using the following steps:

  1. Connected to the SQLite database with RSQLite.
  2. Retrieved all Node rows whose Content column is non-null (stored as a DOCX binary blob).
  3. Wrapped each blob in rawConnection() and passed it to officer::read_docx() to extract paragraph text.
  4. Applied the regular expression \{[^}]+\} with gregexpr() / regmatches() to find every {...} occurrence in each node.
  5. Classified each tag against the canonical set and grouped anomalies by type.
  6. Joined to NodeHierarchy and DocType to show which document types each affected node belongs to.
